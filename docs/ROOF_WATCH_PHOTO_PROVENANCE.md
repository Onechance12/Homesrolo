# Roof Watch photo provenance and release record

This record covers the documentary images introduced with the August 20, 2026
Roof Watch search release. It exists so a future editor can tell which files
were reviewed, what was changed, and what the images are allowed to claim.

## Publication basis

- The operator supplied the source files from a private roof-photo library and
  explicitly asked Homesrolo to use selected roof photographs in this release.
- Before merge, the operator must separately confirm that each selected source
  was created by the operator or is covered by permission or a license allowing
  public commercial publication. Possession in a photo library is not, by
  itself, a copyright or model-release record.
- The repository contains publication derivatives only. It does not contain
  source-library paths, GPS coordinates, addresses, homeowner names, or device
  identifiers.
- A visual review rejected images that showed obsolete contractor branding or
  a worker whose publication permission was not established.
- These images are archival documentation examples. They are not evidence that
  Homesrolo or Roof Watch inspected a particular home, found a defect, caused or
  observed storm damage, performed the pictured work, or obtained an insurance
  result.
- If ownership, licensing, or a pictured person&rsquo;s permission is later
  disputed, remove the affected derivative while the source is reviewed.

## Allowed transforms

The full publication files are 1200-pixel WebP derivatives. Each has a
640-pixel WebP derivative for responsive delivery. The social card is a
1200-by-630 JPEG crop for broad link-preview compatibility. Processing is
limited to orientation correction, reviewed cropping, resizing, metadata
removal, and lossy encoding. No object, condition, person, damage mark, brand,
or roof feature was added, removed, blurred, or generated.

Before every release, the public-web guard checks the photo directory for EXIF,
GPS, XMP, device, creator, and obsolete-brand markers; checks each 640-pixel
derivative; and confirms that every sitemap image exists. Human review remains
required for visible faces, addresses, plates, documents, brands, and caption
accuracy because a metadata scan cannot evaluate the pixels.
